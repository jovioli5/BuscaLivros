#  BuscaLivros

**Projeto Web com HTML, CSS e JavaScript para busca de livros**  
Uma aplicação web simples e elegante para busca de livros utilizando a API do Google Books.


##  Sobre o Projeto

Um aplicativo front-end desenvolvido com **JavaScript puro** que oferece uma interface limpa, responsiva e de fácil utilização.


##  Funcionalidades

- Busca por título, autor ou palavra-chave  
- Seleção de quantidade de resultados (10, 20 ou 30)  
- Cartões simplificados com título e autor  
- Layout totalmente responsivo  


## 🧠 Diferenciais

- Orientação a objetos — Classes `Livro` e `ResultadoBusca`  
- Sem dependências externas — apenas HTML, CSS e JavaScript puro

#  BuscaLivros

**Projeto Web com HTML, CSS e JavaScript para busca de livros**  
Uma aplicação web simples e elegante para busca de livros utilizando a API do Google Books.


## 📖 Sobre o Projeto

Um aplicativo front-end desenvolvido com **JavaScript puro** que oferece uma interface limpa, responsiva e de fácil utilização.

##  Funcionalidades

- Busca por título, autor ou palavra-chave  
- Seleção de quantidade de resultados (10, 20 ou 30)  
- Cartões simplificados com título e autor  
- Layout totalmente responsivo  


##  Diferenciais

- Orientação a objetos — Classes `Livro` e `ResultadoBusca`  
- Sem dependências externas — apenas HTML, CSS e JavaScript puro  


##  Tecnologias Utilizadas

| Tecnologia               | Descrição |
|--------------------------|-----------|
| HTML5                    | Estrutura semântica da página |
| CSS3                     | Flexbox, Grid, animações e design responsivo |
| JavaScript ES6+          | Async/Await, Classes, Módulos, API Fetch |
| API do Google Books v1   | Fonte dos dados dos livros |
| Font Awesome 6.5.1       | Ícones |
| Google Fonts (Inter)     | Tipografia moderna |


##  Como Executar

### Pré-requisitos

- Navegador web moderno (Chrome, Firefox, Edge, Safari)  
- Conexão com internet
